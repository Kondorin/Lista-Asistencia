Info
Este es un proyecto para hacer una pagina web dinámica simulando ser
una lista de asistencia la cual podrá manejar un maestro. 
Se creo en la carrera de Ingenieria en Sistemas de Información en la Universidad de Sonora. Uso básico de CRUD con PHP, HTML Y CSS. Cuenta con la temática de una lista de asistencia de una materia donde se 
asignan tareas y se pone 3 examenes por curso.

Uso
El Maestro, o el usuario que utilice la pagina contará con 3 grupos asignados.
El maestro tendrá acceso al area de calificaciones y al area de lista de asistencia. También podrá.
- Agregar Alumnos
- Agregar Tareas
- Agregar fechas/dias
- Poner asistencia o calificaciones a cada uno de sus alumnos

- La página dinamicamente irá haciendo el calculo o promedio de la calificacion.

Configuración
Se instala el servidor apache con XAMPP, se crea una base de datos llamada "maestro" y se importa el script que se encuentra en la carpeta raiz del proyecto a la base de datos.
